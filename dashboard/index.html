Method. Implied value = TVL × category multiple × growth × maturity × chain breadth. Velocity = 7d TVL change rescaled 0–100. Risk is a 0–100 proxy from four flags the snapshot can see — single-chain, very young, violent 7d swing, tiny TVL — and the risk-adjusted value discounts the implied value by half the risk score. The snapshot carries no holder, audit or lock data, and this radar never pretends it does: check the protocol's own pages before depositing, and never pay to claim.
